# ShacoPal — 测试可玩版本2

这是一个使用 Unreal Engine 5.4 制作的帕鲁玩法原型。目前已经可以完成探索、采集、建造、捕捉、帕鲁管理、自由战斗、回合制战斗、世界存档和局域网联机。

> 当前版本主要用于玩法测试，并非完整商业游戏。联机使用局域网 Session，主机退出后房间会关闭。

## 快速开始

### 已获得打包版本

解压完整游戏目录后运行 `FinalProject.exe`。不要只复制 `.exe`，它需要与旁边的 `Content`、`Engine` 等打包文件一起使用。

### 从本仓库运行

本仓库主要提供 UE 工程源码和资产：

1. 安装 Unreal Engine 5.4 与 Visual Studio/Rider 的 C++ 开发环境。
2. 打开 `FinalProject.uproject`。
3. 编译 `FinalProjectEditor Win64 Development`。
4. 从 `MainMenu` 地图开始运行。

开发者配置说明见 [存档与联机设置](Docs/SAVE_MULTIPLAYER_SYSTEM_SETUP.md) 和 [材料与建造设置](Docs/BUILDING_MATERIAL_SYSTEM_SETUP.md)。

## 主菜单

| 入口 | 作用 |
| --- | --- |
| 开始游戏 | 创建一个新的单机世界存档并进入游戏。 |
| 继续游戏 | 打开存档列表；点击世界卡片读取对应世界。没有存档时可点击返回。 |
| 联机游戏 | 进入房间页面，可以创建新联机世界、搜索 `shacoPal` 房间并加入。 |

如果想把**正在玩的单机存档**开放给朋友，请进入该存档后按 `Esc`，选择“开放联机”。系统会先保存当前世界，再以 Listen Server 方式重新载入同一世界。

## 基本玩法

1. 用左键攻击树木或矿石，资源会掉落到地面。
2. 走近掉落物会自动拾取；按 `B` 查看可堆叠材料。
3. 按 `C` 打开建筑清单，点击图案后会在角色前方生成建筑虚影。
4. 移动角色调整位置，滚轮旋转；虚影有效时按左键消耗材料并建造。
5. 削弱野生帕鲁后按 `Q` 投球。捕捉成功的帕鲁会进入背包，背包满后进入仓库。
6. 用方向键选择帕鲁，按 `F` 召唤。召唤帕鲁会跟随玩家并参与自由战斗。
7. 按 `P` 可进入回合制战斗，通过界面使用技能、切换帕鲁、投球或使用药品。

## 存档说明

- 游戏世界支持周期性自动存档，也可以按 `Esc → 存档` 手动保存。
- 回合制战斗进行中会跳过存档，避免保存不完整的战斗中间态；请在战斗结束后保存。
- 存档包含角色状态与位置、材料背包、帕鲁背包/仓库、技能数据和世界建筑。
- 建议退出前手动保存一次，再返回主界面。
- 不要随意删除游戏的 `Saved/SaveGames` 目录；它还保存本机玩家身份，联机重连时会用它找回该玩家的数据。

## 局域网联机

### 创建一个新房间

1. 主机在主菜单选择“联机游戏”。
2. 输入房间名并点击“创建房间”。
3. 其他玩家选择“联机游戏 → 搜索房间”。
4. 在列表中找到房间并点击加入。

### 开放已有单机存档

1. 主机通过“继续游戏”进入需要开放的世界。
2. 按 `Esc → 开放联机`，等待保存和地图重载完成。
3. 客户端在主菜单进入“联机游戏”，搜索后加入。

### 联机存档规则

- 主机保存唯一的权威世界档。
- 客户端点击存档时，实际是向主机发送保存请求，不会另存一份互相冲突的世界。
- 主机存档会保留已经离线的客户端角色记录。该客户端以后使用同一本机身份加入同一世界时，会恢复之前的材料、帕鲁和角色状态。
- 主机返回主菜单或关闭游戏后，房间会消失；需要重新进入世界并再次开放联机。

## 常见问题

### 搜索不到房间

- 确认主机已经完成创建房间或“开放联机”的地图重载。
- 当前版本仅面向同一局域网；公网直连、Steam/EOS 大厅尚未接入。
- 确认 Windows 防火墙允许 `FinalProject.exe` 或 `UnrealEditor.exe` 进行专用/公用网络通信。
- 主机刚返回主菜单时搜索结果为 0 是正常现象，重新开放世界后再搜索。

### 点击继续游戏但没有存档

点击存档页面的“返回”，选择“开始游戏”创建新世界。存档列表每次打开都会重新读取磁盘。

### 手动存档失败

先退出回合制战斗并等待其他保存完成。联机客户端的保存请求可能因主机正在写盘或短时间重复请求而被拒绝，可以稍后再试。

### 同一台电脑运行两个测试实例

开发测试时请给两个进程不同的本地身份，例如：

```text
-PlayerProfile=Host1
-PlayerProfile=Client1
```

正常情况下，不同电脑上的玩家无需添加该参数。

## 当前限制

- 联机暂时使用 `OnlineSubsystemNull`，适合局域网和同机多进程测试，不支持互联网大厅。
- Listen Server 由主机承担服务器职责；主机离开后所有客户端会返回主菜单。
- 这是玩法原型，美术、音效、数值平衡、地图内容与错误提示仍会继续迭代。
