# 可玩测试版1

这是基于 Unreal Engine 5.4 开发的帕鲁玩法原型。当前版本已经完成核心玩法闭环，可用于单机游玩测试与后续功能迭代。

## 已实现内容

- 自由探索、角色与帕鲁属性、技能执行及战斗表现
- 帕鲁捕捉、队伍编成、仓库存取、技能学习与技能更换
- 回合制战斗，以及敌方多只帕鲁依次上场的战斗管理
- 野生帕鲁随机巡逻、视觉感知、受击追击、脱离后返回出生区域
- 区域生态生成器：按容量和随机时间间隔补充指定帕鲁种类
- 战斗与仓储界面的蓝图控件化重构

## 运行环境

- Unreal Engine 5.4
- Windows 64 位开发环境

使用 Unreal Engine 5.4 打开 `FinalProject.uproject`，编译 `FinalProjectEditor` 后即可在编辑器中运行测试关卡。
